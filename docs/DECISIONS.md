- 2026-11-17 — A local model writes the card protocol, not the op list of ARCHITECTURE §3.2: per new segment it gives a type (new, recap, agenda, other), a header from a fixed list, a topic title and its cards; the provider turns that into `add_topic` and `add_card` ops, takes cards only from segments typed new, and reuses a topic whose title matches or shares a telling word. It cannot suggest a move or a merge. The schema is built per request so the model cannot name a segment, header or owner that does not exist — a 4B model follows this at 88% card match where it managed 24–71% on the op list; the engine's rules still judge every op — Claude

- 2026-11-17 — A structurer run is tried twice before it counts as failed, and a batch is always sent in meeting order — a failed run's segments used to rejoin behind later ones, and a failure on a meeting's last run left its segments unstructured — Claude
- 2026-11-17 — `pnpm golden --paced` waits for each run before playing on, so each run gets one trigger's batch; the gate is still read at 10× as TEST_PLAN §2 says — at 10× the batches depend on how fast the model answers, and paced is what a live meeting gives a model that answers inside 45 s; NOTES records both — Claude
